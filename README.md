# HET IMPEX Diamond Business Manager

A lightweight web app for managing day-to-day diamond business data.

## Features

- Diamond stock management with:
  - Shape
  - Number CTS
  - Manufacturing CTS
- Rough diamond stock management with rough type and stock CTS
- Sales tracking with customer, item, CTS, and auto amount calculation
- Bill generator for printable invoice-style bill preview
- Auto-updated business summary totals
- Local storage persistence in the browser
- JSON data export button

## How to run

1. Open `index.html` in any modern browser.
2. Start adding records in each section.
3. Data is automatically saved in browser storage.
